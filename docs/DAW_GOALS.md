# DAWとしての到達目標と現状（v0.20.0）

| 目標 | 現在の機能 | 次の実装課題 |
| --- | --- | --- |
| 自然言語で音色を調整 | 内蔵音源のパート別プリセット、自然言語でのパラメータ生成・調整、Reference Audioの特徴量比較。VST3は各音源のエディタで設定 | VST3の任意パラメータへ自然言語を安全に対応づける仕組みと変更履歴 |
| 鼻歌からキー・音階・リズム・楽譜 | マイクをローカル解析し、推定キーへ音程を寄せ、BPMと音符グリッドを推定。補正結果の楽譜を表示。v0.20.0で選択パートにNote Clipとして配置 | 録音後の推定キーと拍の手動修正、複数候補の提示、休符・臨時記号の楽譜精度 |
| ピアノロールで作曲 | トラック別Note Clipの追加、移動、長さ、ベロシティ、保存・読込 | 複数ノートの一括編集、コピー／貼付け、より広い編集履歴 |
| 再生位置の表示 | 曲のタイムラインとピアノロールに、AudioContextの時計から再生位置を表示 | Windows実機でのUIと音声のずれの計測・調整 |
| ギター・ベースの生音録音と編集 | 未実装。現行の鼻歌録音は音高イベントだけを解析し、音声データを保存しない | **独立した音声トラック**、入力機器／レベル／遅延補正、波形編集、曲との同期、音声データの保存・再読込を先に設計。その後に単音の音高推定と譜面化を追加。和音の自動採譜は別の課題 |
| Cubase / Logicに近いDAW | 7パートの基本的なアレンジメント、音色選択、VST3、フリーズ、JSON保存 | 上記音声トラックに加え、ミキサー、オートメーション、安定した低遅延録音、入出力管理、プロジェクト互換性の段階的実装 |

## 録音の境界

鼻歌モードでは引き続きマイクの生音を保存しない。ギター・ベースの生音録音は別の明示的な録音モードとして実装し、録音する入力と保存先をユーザーに示す。音声をただMIDIへ置換すると演奏のニュアンスが消えるため、生音のクリップと採譜したノートを別々に保持する。

## 今回の範囲

鼻歌を補正して生成したノートを、選択中のパートの再生開始位置から最大16拍のNote Clipへ分割して配置する。ピアノロール編集と既存Project JSONの保存・読込をそのまま利用する。曲長を超える場合やフリーズ中は配置せず、状態を変更しない。音声クリップの録音・保存・波形表示はまだ含まれない。
