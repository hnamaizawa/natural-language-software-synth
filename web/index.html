Natural Language Software Synth

自然言語から音源を生成し、鍵盤・MIDI・ドラムパッドに加えて、マイクへ歌った鼻歌をMIDIノート相当のメロディーデータとして録音できます。

「音源を有効化」を押すとFactory PCMバッファも準備します。

Subtractive Synth
SAMPLE 現在の音色でサンプル演奏 生成した音色を短いフレーズで確認できます。
＋ 自分のサンプル演奏フレーズを登録

1行=1ステップ。形式は「音名またはMIDIノート | 拍数 | Velocity」です。和音はカンマ区切り、休符は R。ギターの和音は登録フレーズでも高速ストロークとして発音をずらします。ドラムは例: Kick=36 / Snare=38 / Closed Hat=42。

🎤 鼻歌からメロディーを録音

マイク音声そのものは保存しません。単音の鼻歌をブラウザ内で解析し、MIDIノート相当の音程・長さ・Velocityへ変換します。

音色をグラフィカルに調整

スライダーを動かすと即座に現在の音へ反映されます。ギターではAmp Model / Drive、グランドピアノではHammer / Resonance / Damper Noiseなどを調整できます。

ENGINE CONTRACT

全音源と鼻歌メロディーで同じ noteOn / noteOff 契約を共有

PCMフレットレス、PCMギター＋アンプ、PCMグランドピアノ、PCMドラム、FMエレピ、減算シンセのすべてを同じ演奏APIから呼び出します。鼻歌録音も音声を保存せず、検出したノートイベントだけを同じAPIで試聴します。
